Troubleshooting real-time updates

1 Enable Background App Refresh

Settings → General → Background App Refresh → Caraoke → ON. Without this, the widget pauses when the app is suspended.

2 Allow Live Activities

Settings → Caraoke → Live Activities → ON. Lock Screen and Dynamic Island updates require this permission.

3 Tap the cover to resync

If lyrics drift, tap the album art or vinyl disc. Caraoke re-queries Spotify and LRCLIB in the background without launching the app.

4 Use caraoke://lyrics deep link

Tapping anywhere on the Small widget opens the full karaoke page via the caraoke://lyrics URL scheme.

5 StandBy

Place iPhone horizontally on a charger, then select the Caraoke lyrics widget to enable StandBy night mode.
