Architecture

The whole stack is six things

No backend. No database. No auth server. The product is a client that reads what your phone is already playing and paints lyrics on a system surface. Every third-party line below is either free at our scale or already paid for.

Layer Choice Why this and not the alternative Cost
App Swift 5.9 · SwiftUI · iOS 26 target CarPlay Dashboard lyric mirroring requires the iOS 26 Live Activity family API. No cross-platform path exists for this surface. $0
Build system XcodeGen project.yml + Fastlane + GitHub Actions Declarative project file diffs cleanly in git; cloud CI means no local Xcode dependency for signing or TestFlight. $0
System surfaces ActivityKit (Live Activities, Dynamic Island) + WidgetKit The only Apple-sanctioned way to put live text on the CarPlay Dashboard, Lock Screen and Home Screen simultaneously. $0
Lyrics LRCLIB + local fallback cache Open, zero-cost, LRC-native timing. The fallback cache is what keeps the app working when the API is slow or down — the #1 competitor complaint. $0
Monetization RevenueCat 5.88.0 (StoreKit wrapper) Receipt validation, entitlement state and paywall experiments without writing a server. Apple still processes the payment. $0 → 1%
Analytics TelemetryDeck (planned) + MetricKit (built in) Privacy-first, no ATT prompt, no IDFA. MetricKit covers crashes, hangs and battery with zero SDK. $0

Deliberately absent

Each of these was considered and rejected.

  • Supabase / Firebase A DB to store event rows we do not need.
  • Sentry / Crashlytics MetricKit already reports fatal crashes.
  • Remote config TestFlight is the release cadence.
  • Support SDK A mailto: link is enough pre-revenue.

The demand signal

Dynamic Lyrics adds ~20K–38K installs/mo; newcomer CARFACE jumped to +4.4K/mo in 60 days. Demand for lyrics on car screens is surging.

The pricing extremes

Market splits between underpriced utilities ($4.99/yr Dynamic Lyrics) and aggressive subscription traps ($39.99/yr Lyrix, $35.99/yr Musixmatch).

The KaraFun validation

KaraFun pulls ~$50K–$80K/mo ($9.99/mo, $59.99/yr) by leaning purely into karaoke and singing. Users willingly pay $10/mo for singing, not plain text viewing.

Where Caraoke wins

A focused $9.99/yr car karaoke app that doesn't freeze on phone calls, doesn't lag on song skips, and starts in 1 tap without shortcuts.

Why 7 days on annual, 3 on monthly

  • Weekend coverage A Monday-start 3-day trial dies Thursday — the user never sees a weekend drive, which is the product's best moment.
  • Usage is driving-gated ~2 sessions/day max. Seven days yields ~14 drive sessions plus a weekend: enough for habit and loss aversion.
  • Proportion Seven days free on a $1.99/month plan is 23% of a month. Seven days on an annual plan is proportionate.
  • Data 84% of 3-day cancellations happen on day 0–1, versus 64% for 7-day. Shorter trials trigger panic cancellation, not intent.

The 30-second CEO read

The product is real, the market is proven, the cost base is trivial and the category leader is beatable on the one thing that matters — reliability. The single highest-value action is not a feature. It is getting Build 39 onto a real CarPlay head unit and proving sync survives skips. Everything else on this page is arithmetic.
